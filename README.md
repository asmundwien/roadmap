# Roadmap

A live, read-only visualization of [wayfinder](https://github.com/mattpocock)-organized projects on GitHub.

Roadmap auto-discovers every repo of yours that carries a `wayfinder:map` issue and renders each effort as a living map: the dependency graph of tickets — closed, claimed, frontier, blocked — alongside the decisions made so far and the fog still ahead. It polls the GitHub API and updates as agent sessions make progress.

First observed project: [gainstage](https://github.com/asmundwien/gainstage).

## Status

Pre-build. The work is organized by a wayfinder map in this repo's issues — see the issue labelled `wayfinder:map`.
