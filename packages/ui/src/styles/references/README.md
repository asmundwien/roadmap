# Reference tokens

Reference tokens describe reusable design values without assigning them a UI purpose. A shade in a palette is a reference value; the color chosen for primary text is a semantic role. References may use other references where useful.

Add choices here when shared roles need them. Context-dependent roles and component-specific decisions do not belong here.

This distinction follows [Material's reference and system token model](https://m3.material.io/foundations/design-tokens/overview). [MUI's palette guide](https://mui.com/material-ui/customization/palette/) shows how shades can support role-based colors; it does not prescribe this project's CSS layers.
